# Downloads Storage Branch

This branch contains all downloadable files for the QFBD Research Group website, including seminar slides, research papers, and presentations.

## Purpose

This branch serves as a dedicated storage location for large files that are referenced from the main website. By keeping these files in a separate branch, we:

- Keep the main repository lightweight
- Maintain fast clone times for the website
- Provide stable URLs for downloadable content
- Organize all research materials in one place

## File Organization

All files are stored in the root directory of this branch for easy access and simple URL structure.

## Usage

Files can be accessed directly via GitHub's raw content URLs:
```
https://raw.githubusercontent.com/fewbody/fewbody.github.io/downloads-storage/[filename]
```

## File Types

This branch contains:
- **PDF files**: Research papers, seminar slides, lecture notes
- **PowerPoint presentations**: .ppt and .pptx files
- **Archive files**: .zip files containing code and data
- **Other research materials**: Various formats as needed

## Maintenance

- Files are added as needed for new seminars and research materials
- All files are committed with descriptive messages

## Access from Website

The main website references these files through links in:
